# Adopt a single enterprise visual language for the desktop workbench

Status: accepted (2026-09-06)

AutoLabeler adopts a dark navy navigation rail with a cool-mist light canvas,
white workflow surfaces, cool teal primary actions, and champagne-gold brand
details. The palette, typography, focus states, and restrained elevation are
centralized in `gui/design_system.py` and `gui/theme_manager.py`; existing
workflow layouts, field semantics, task lifecycle, and safety confirmations
remain unchanged. This replaces the earlier warm/gradient-heavy direction so
the product reads as a calm, high-trust production tool during long sessions.
