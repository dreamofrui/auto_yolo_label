# Domain Docs

This repository uses the single-context layout.

## Before Exploring

Read these resources when they exist:

- Root `CONTEXT.md`
- Relevant ADRs under `docs/adr/`

If they do not exist, proceed silently. Domain-modeling workflows create them
lazily when terminology or architectural decisions are resolved.

Use terminology defined in `CONTEXT.md`. If a proposal contradicts an ADR,
identify the conflict explicitly rather than silently overriding it.

## Layout

```text
/
|-- CONTEXT.md
`-- docs/adr/
```
