## 软件简介

AutoLabeler 是一款智能图片标注工具，结合手动标注和 YOLO 自动推理，大幅减少标注工作量。

**核心工作流程**：
```
扫描 → 抽样 → 手动标注 → 训练 → 推理 → 还原 → (可选) 转换
```

---

## 快速开始

### 第一次使用

1. **准备站点文件夹**
   ```
   站点文件夹/
   ├── 类别A/
   │   ├── 产品1/
   │   │   ├── 图片001.jpg
   │   │   └── 图片002.jpg
   │   └── 产品2/
   │       └── ...
   └── 类别B/
       └── ...
   ```

2. **扫描** - 扫描站点文件夹，建立图片索引

3. **抽样** - 从每个产品抽取部分图片用于手动标注

4. **手动标注** - 使用标注工具（如 LabelImg）标注抽样的图片

5. **训练** - 使用标注数据训练 YOLO 模型

6. **推理** - 使用训练好的模型自动标注剩余图片

7. **还原** - 将标注文件还原到原始文件夹结构

### 3. 抽样功能

**作用**: 从每个产品中抽取部分图片用于手动标注

**参数说明**:

| 参数 | 默认值 | 说明 | 推荐设置 |
|------|--------|------|----------|
| **抽样模式** | count | 选择抽取策略 | 根据场景选择 |
| **抽样数量** | 40 | 固定数量模式：每产品抽多少张 | 20-50 |
| **抽样比例** | 0.3 | 比例模式：抽取30% | 0.2-0.5 |
| **全抽阈值** | 35 | 图片数≤此值时全部抽取 | 20-50 |
| **训练集比例** | 0.9 | 90%训练集，10%验证集 | 0.8-0.9 |

#### 抽样模式详解

**1. count (固定数量)** - 推荐新手使用

```
适用场景: 每个产品图片数量差异较大
工作方式: 每个产品都抽取固定数量的图片
```

**用例**:

| 用例名称 | 参数设置 | 场景描述 | 抽取效果 |
|----------|----------|----------|----------|
| 用例1: 默认配置 | 模式: count<br>数量: 40<br>全抽阈值: 35 | 产品图片数差异大 | 产品A(1000张)→抽40张<br>产品B(50张)→抽40张<br>产品C(30张)→全抽30张 |
| 用例2: 小规模抽样 | 模式: count<br>数量: 16<br>全抽阈值: 16 | 想每个产品抽16张<br>少于16张全抽 | 产品A(100张)→抽16张<br>产品B(20张)→抽16张<br>产品C(10张)→全抽10张 |
| 用例3: 大规模抽样 | 模式: count<br>数量: 100<br>全抽阈值: 50 | 需要大量样本 | 产品A(1000张)→抽100张<br>产品B(80张)→全抽80张 |

---

**2. ratio (比例模式)** - 推荐图片数量均衡的场景

```
适用场景: 各产品图片数量相近
工作方式: 按比例抽取
```

**用例**:

| 用例名称 | 参数设置 | 场景描述 | 抽取效果 |
|----------|----------|----------|----------|
| 用例1: 30%抽样 | 模式: ratio<br>比例: 0.3<br>全抽阈值: 20 | 每个产品抽30% | 产品A(100张)→抽30张<br>产品B(200张)→抽60张<br>产品C(15张)→全抽15张 |
| 用例2: 轻量级抽样 | 模式: ratio<br>比例: 0.15<br>全抽阈值: 15 | 快速验证 | 产品A(100张)→抽15张<br>产品B(200张)→抽30张 |
| 用例3: 重度抽样 | 模式: ratio<br>比例: 0.5<br>全抽阈值: 30 | 需要更多样本 | 产品A(100张)→抽50张<br>产品B(80张)→全抽80张 |

---

**3. mixed (混合模式)** - 推荐高级用户

```
适用场景: 想要平衡比例和数量
工作方式: 按比例计算，但限制在最小和最大值之间
```

**用例**:

| 用例名称 | 参数设置 | 场景描述 | 抽取效果 |
|----------|----------|----------|----------|
| 用例1: 标准混合 | 模式: mixed<br>比例: 0.3<br>最小: 20<br>最大: 50<br>全抽: 20 | 平衡各产品样本量 | 产品A(200张)→比例60→限制50张<br>产品B(100张)→比例30→抽30张<br>产品C(50张)→比例15→提升20张<br>产品D(15张)→全抽15张 |
| 用例2: 保守混合 | 模式: mixed<br>比例: 0.2<br>最小: 10<br>最大: 30<br>全抽: 15 | 控制总样本量 | 产品A(200张)→比例40→限制30张<br>产品B(50张)→比例10→抽10张 |

---

**全抽阈值** - 所有模式通用

```
作用: 当产品图片数 <= 阈值时，全部抽取
目的: 保证样本少的产品也能参与训练
优先级: 最高，优先于模式判断
```

**实际效果**:

| 全抽阈值 | 产品图片数 | 结果 |
|----------|------------|------|
| 35 | 30 张 | 全抽 30 张 |
| 35 | 35 张 | 全抽 35 张 |
| 35 | 100 张 | 按模式抽取 |
| 16 | 16 张 | 全抽 16 张 |
| 16 | 20 张 | 按模式抽取 |

---

**抽样策略建议**:

| 场景 | 推荐模式 | 参数建议 |
|------|----------|----------|
| 新手入门 | count | 数量: 40，全抽: 35 |
| 每产品固定16张 | count | 数量: 16，全抽: 16 |
| 产品图片均衡 | ratio | 比例: 0.3，全抽: 35 |
| 产品图片差异大 | mixed | 比例: 0.3，最小: 20，最大: 50 |

**操作步骤**:
1. 选择站点文件夹
2. 选择输出文件夹（通常是 `.autolabeler/database`）
3. 设置抽样参数
4. 点击"开始抽样"

**结果**: 在输出文件夹生成 YOLO 训练数据集结构

### 4. 训练功能

**作用**: 使用手动标注的数据训练 YOLO 模型

**参数说明**:

| 参数 | 默认值 | 说明 | 推荐设置 |
|------|--------|------|----------|
| **训练轮次** | 100 | 训练多少轮 | 50-150 |
| **批次大小** | 自动 | -1=自动检测 | 保持自动 |
| **图片尺寸** | 640 | 训练图片尺寸 | 640 或 1280 |
| **计算设备** | 自动 | auto/cpu/0/mps | 保持自动 |
| **早停轮次** | 50 | 多少轮无改善则停止 | 50 |
| **Box增益** | 7.5 | 小目标检测时可降低此值 | 4.0-7.5 |

**操作步骤**:
1. 选择 data.yaml（抽样生成的配置文件）
2. 选择基础模型（如 yolo11n.pt）
3. 选择输出目录
4. 设置训练参数
5. 点击"开始训练"

**结果**: 输出目录生成 `best.pt`（最佳模型）

**训练指标说明**:
- **mAP50**: IoU=0.5 时的平均精度，越高越好（0-1）
- **mAP50-95**: IoU=0.5-0.95 的平均精度，越高越好（0-1）

**Box增益参数说明**:
- **作用**: 控制 box loss gain，影响模型对小目标的检测能力
- **默认值**: 7.5
- **何时调整**: 当标注的目标物体很小时（如小零件、远处的物体）
- **降低值**: 设为 4.0-5.0 可以检测更小的物体（但可能增加误检）
- **症状**: 如果训练时显示"标注框很少"或 mAP50 始终为 0，可能是目标太小

### 5. 推理功能

**作用**: 使用训练好的模型自动标注剩余图片

**参数说明**:

| 参数 | 默认值 | 说明 | 推荐设置 |
|------|--------|------|----------|
| **置信度阈值** | 0.25 | 低于此值的检测框将被过滤 | 0.25-0.5 |
| **IoU 阈值** | 0.45 | 非极大值抑制的 IoU 阈值 | 0.45 |
| **批处理大小** | 自动 | -1=自动检测 | 保持自动 |
| **计算设备** | 自动 | auto/cpu/0/mps | 保持自动 |

**操作步骤**:
1. 选择模型文件（训练生成的 best.pt）
2. 选择站点文件夹
3. 设置推理参数
4. 点击"开始推理"

**结果**: 在原始图片位置生成对应的 .txt 标注文件

**性能优化提示**:
- CPU 环境：batch_size 自动设为 8，避免卡顿
- GPU 环境：batch_size 根据显存自动调整

## 常见问题

### Q1: 抽样数量、比例、混合模式有什么区别？

**A**:
- **数量模式**: 简单粗暴，每个产品抽固定张数
- **比例模式**: 按百分比抽取，适合图片均衡的场景
- **混合模式**: 智能调整，避免太少或太多

**例子**:
```
产品A: 1000 张图片
产品B: 50 张图片

数量模式(40张): A抽40张，B抽40张
比例模式(30%):  A抽300张，B抽15张
混合模式(30%, 20-50): A抽50张(上限)，B抽20张(下限)
```

### Q2: 全抽阈值是什么？

**A**: 保护小样本产品。设为 35 时，任何产品如果图片数 ≤ 35，全部抽取。

### Q3: 训练时 batch_size 设多少？

**A**: 推荐保持**自动（-1）**。程序会根据设备自动选择最优值：
- CPU: 8
- GPU (24GB+): 32
- GPU (12GB+): 16
- GPU (6GB+): 8

### Q4: 推理时置信度设多少合适？

**A**:
- **0.25**: 默认值，召回率高，可能有误检
- **0.5**: 平衡点
- **0.7**: 精度高，可能漏检

### Q5: 训练多少轮合适？

**A**:
- **快速验证**: 10-20 轮
- **正常训练**: 50-100 轮
- **精细训练**: 100-150 轮

建议先训练 10 轮看效果，再决定是否增加。

### Q6: CPU 和 GPU 训练差异？

**A**:
- **CPU**: 速度慢，但保证可用
- **GPU**: 速度快 10-50 倍，推荐使用
- 设备选择"自动"会自动检测并使用 GPU

### Q7: 抽样后图片在哪里？

**A**: 在输出文件夹的 `images/train/` 和 `images/vals/` 中。

### Q8: 推理后的标注在哪里？

**A**: **在原始图片位置**，与图片同目录，同名但扩展名为 .txt

### Q9: 如何查看训练效果？

**A**:
1. 观察训练指标的 mAP50 值（越高越好）
2. 训练完成后进行推理，人工检查几张图片的标注质量

### Q10: 训练时 mAP50 始终为 0 是什么原因？

**A**: 可能是**目标太小**导致的。YOLO 会过滤掉过小的标注框（小于图片尺寸约 2%）。

**解决方法**:
1. **运行诊断工具**: `python debug_yolo_data.py database/data.yaml`
2. **降低 Box增益 参数**：
   - 超过50%极小框(<0.01): 设为 2.0-3.0
   - 超过50%小框(0.01-0.02): 设为 4.0-5.0
3. **增大训练图片尺寸**: 从 640 改为 1280
4. **检查类别 ID**: 标注文件中的类别 ID 必须与 data.yaml 一致（从 0 开始）
5. **检查标注文件**: 确保每张训练图片都有对应的 .txt 文件

**症状分析**:
- 如果训练日志显示"标注框很少" → 标注框被过滤
- 如果推理输出全是空文件 → 模型没学到东西（数据问题）

### Q11: Box增益参数应该怎么设置？

**A**:
- **默认值 7.5**: 适合中等大小的目标（占图片 5% 以上）
- **4.0-5.0**: 适合小目标（占图片 2-5%）
- **低于 4.0**: 极小目标（但可能增加误检）

**判断方法**: 查看训练日志中的"标注框数量"，如果明显少于实际标注数，说明目标被过滤了，需要降低此值。

### Q12: 可以跳过手动标注直接训练吗？

**A**: **不可以**。YOLO 训练需要标注数据，必须先抽样后手动标注才能训练。

## 最佳实践

### 推荐工作流程

```
1. 扫描站点文件夹
2. 抽样（推荐 count 模式，数量 40，全抽阈值 35）
3. 使用 LabelImg 手动标注 database/labels/train/ 中的图片
4. 训练（先训练 10 轮验证流程，再训练 100 轮正式模型）
5. 推理（使用训练好的 best.pt）
6. 还原（将标注还原到原始位置）
7. 转换（如需 VOC 格式）
```
