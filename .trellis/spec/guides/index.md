# Cross-Layer Guides

Use these guides when a change crosses the page/worker/core/utils boundary or
introduces a helper that might duplicate an existing contract.

| Guide | Use when |
| --- | --- |
| [Cross-layer data flow](./cross-layer-thinking-guide.md) | A feature changes Flow/Independent data, task state, paths, annotations, or user-visible errors across layers. |
| [Code reuse](./code-reuse-thinking-guide.md) | A new helper, constant, parser, path rule, or status transition looks similar to existing code. |
